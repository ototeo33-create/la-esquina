# La Esquina

Prototipo interactivo de una aplicación móvil para una tienda de barrio: catálogo por categorías, pedido con casillas y formulario de entrega.

Trabajo académico de **Nicolás Gallego Suárez** para *Fundamentos de Psicología del Usuario* (CUN), noviembre de 2026.

Es un único archivo (index.html), sin dependencias que instalar. Usa Google Fonts para la tipografía.
